# پروژه هوش مصنوعی پیش‌بینی قیمت خانه
## House Price Prediction AI

این پروژه یک سیستم یادگیری ماشین برای پیش‌بینی قیمت خانه بر اساس سه ویژگی زیر است:

- متراژ خانه (Area)
- تعداد اتاق‌ها (Rooms)
- سن خانه (Age)

در این پروژه از الگوریتم **Linear Regression** استفاده شده و مدل آموزش‌دیده از طریق یک API با استفاده از **FastAPI** نیز قابل استفاده است.

## امکانات پروژه

- تولید دیتاست مصنوعی شامل ۱۰۰ نمونه
- آماده‌سازی و بررسی داده‌ها
- آموزش مدل یادگیری ماشین
- ارزیابی مدل با MAE و R²
- استفاده از Cross Validation
- مقایسه الگوریتم‌های مختلف
- Feature Engineering
- Hyperparameter Tuning
- ذخیره و بارگذاری مدل با Joblib
- دریافت اطلاعات خانه از کاربر
- پیش‌بینی قیمت خانه با پیام‌های فارسی
- ارائه API برای پیش‌بینی قیمت خانه
- اعتبارسنجی ورودی و خروجی با Pydantic
- مستندات تعاملی API با Swagger UI
- مدیریت خطاهای API

## آموزش مدل

برای آموزش مدل نهایی:

```bash
python final_model.py
```

مدل آموزش‌دیده در مسیر زیر ذخیره می‌شود:

```text
models/final_house_model.pkl
```

## پیش‌بینی مستقیم قیمت خانه

برای اجرای برنامه:

```bash
python predict_final.py
```

برنامه اطلاعات زیر را از کاربر دریافت می‌کند:

1. متراژ خانه
2. تعداد اتاق‌ها
3. سن خانه

سپس قیمت تخمینی را نمایش می‌دهد.

## اجرای API با FastAPI

برای راه‌اندازی API از دستور زیر استفاده کنید:

```bash
uvicorn app.main:app --reload --port 8010
```

پس از اجرای موفق برنامه، API در آدرس زیر در دسترس خواهد بود:

```text
http://127.0.0.1:8010
```

### مستندات Swagger

برای مشاهده و آزمایش مسیرهای API به آدرس زیر مراجعه کنید:

```text
http://127.0.0.1:8010/docs
```

### مسیرهای API

| Method | Endpoint | توضیحات |
|---|---|---|
| GET | `/` | بررسی اجرای API |
| GET | `/health` | بررسی وضعیت API و مدل |
| POST | `/predict` | پیش‌بینی قیمت خانه |

### نمونه درخواست پیش‌بینی

```json
{

```

| ویژگی | حداقل | حداکثر |

در صورت نامعتبر بودن اطلاعات، API پاسخ HTTP 422 برمی‌گرداند.

## ارزیابی مدل

برای ارزیابی مدل از معیارهای زیر استفاده شده است:

- **MAE:** میانگین قدرمطلق خطای پیش‌بینی؛ مقدار کمتر بهتر است.
- **R²:** میزان توانایی مدل در توضیح تغییرات داده‌ها؛ مقدار نزدیک به یک بهتر است.

نتایج مدل نهایی در اجرای فعلی:

- MAE: حدود 79.99
- R²: حدود 0.989
